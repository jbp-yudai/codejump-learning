# HTMLファイルの基本構造

## 基本構造

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>ページタイトル</title>
</head>
<body>
    <!-- ここにページの内容を書く -->
</body>
</html>
```

## 各タグの役割

### 1. `<!DOCTYPE html>`
- **目的**: HTMLのバージョンを宣言
- **役割**: ブラウザにHTML5として解釈させる
- **位置**: ファイルの先頭（1行目）

### 2. `<html>`
- **目的**: HTMLドキュメント全体のルート要素
- **役割**: すべてのHTML要素の親要素
- **`lang`属性**: 言語を指定（例: `lang="ja"` は日本語）

### 3. `<head>`
- **目的**: ページのメタ情報を格納
- **内容例**:
  - `<meta charset="UTF-8">` - 文字コード
  - `<title>` - ブラウザタブに表示されるタイトル
  - `<meta name="viewport">` - モバイル表示の設定
  - CSSやJavaScriptのリンク
- **注意**: ユーザーには表示されない

### 4. `<body>`
- **目的**: ページに表示される内容を格納
- **内容**: 見出し、段落、画像、リンクなど
- **注意**: ユーザーに見える部分はここに書く

## `src`属性について

`src`属性は、外部リソース（画像、スクリプト、動画など）の場所を指定するために使用します。`src`は「source（ソース）」の略で、「どこから読み込むか」を指定します。

### 主な使用例

#### 1. 画像を表示する (`<img>`タグ)
```html
<img src="photo.jpg" alt="写真の説明">
<img src="images/logo.png" alt="ロゴ">
<img src="https://example.com/image.jpg" alt="外部画像">
```

#### 2. JavaScriptファイルを読み込む (`<script>`タグ)
```html
<script src="script.js"></script>
<script src="js/main.js"></script>
```

#### 3. 動画・音声を埋め込む (`<video>`, `<audio>`タグ)
```html
<video src="movie.mp4" controls></video>
<audio src="sound.mp3" controls></audio>
```

#### 4. 別のページを埋め込む (`<iframe>`タグ)
```html
<iframe src="https://example.com"></iframe>
```

### 重要なポイント

- **パスの指定方法**:
  - 相対パス: `images/photo.jpg`（同じフォルダ内の`images`フォルダから）
  - 絶対パス: `https://example.com/image.jpg`（完全なURL）
- **注意**: ファイルが見つからない場合は、その要素は表示されません（画像なら破損アイコンなど）
- **CSSファイル**: `<link>`タグでは`href`属性を使用します（`src`ではありません）

## `alt`属性について

`alt`属性は、画像の代替テキスト（alternative text）を指定するために使用します。`<img>`タグでは**必須の属性**です。

### なぜ`alt`属性が必要なのか？

#### 1. **アクセシビリティ（アクセシビリティ）**
- 視覚障害のあるユーザーがスクリーンリーダー（音声読み上げソフト）を使用する際、画像の内容を理解できるようにします
- 画像が読み込めない場合でも、画像の内容を伝えることができます

#### 2. **画像が読み込めない場合の代替表示**
- ネットワークエラーやファイルパスの間違いで画像が表示されない場合、`alt`属性のテキストが表示されます
- ブラウザが画像の読み込みを無効にしている場合にも表示されます

#### 3. **SEO（検索エンジン最適化）**
- 検索エンジンが画像の内容を理解するのに役立ちます
- 画像検索で見つけやすくなります

### 使用例

```html
<!-- 良い例: 画像の内容を具体的に説明 -->
<img src="dog.jpg" alt="白い柴犬が公園でボールを追いかけている様子">

<!-- 良い例: 装飾的な画像の場合 -->
<img src="decorative-line.png" alt="">

<!-- 悪い例: 説明が不十分 -->
<img src="photo.jpg" alt="画像">

<!-- 悪い例: alt属性がない（必須なので必ず書く） -->
<img src="photo.jpg">
```

### `alt`属性の書き方のポイント

1. **具体的に書く**: 画像の内容を正確に、簡潔に説明する
2. **装飾的な画像**: ページの見た目だけのための装飾画像は`alt=""`（空文字）にする
3. **長すぎない**: 一般的に125文字以内が推奨されます
4. **「画像」「写真」などの不要な言葉は避ける**: スクリーンリーダーが自動的に「画像」と読み上げるため

### 重要なポイント

- `<img>`タグでは`alt`属性は**必須**です（HTMLの仕様で定められています）
- `alt`属性がないと、HTMLのバリデーション（検証）でエラーになります
- 画像の内容を理解するための重要な情報源です

## まとめ

- `<!DOCTYPE html>` → HTML5の宣言
- `<html>` → ドキュメント全体のルート
- `<head>` → メタ情報（非表示）
- `<body>` → 表示内容（表示される）
- `src`属性 → 外部リソースの場所を指定
- `alt`属性 → 画像の代替テキスト（必須属性、アクセシビリティとSEOに重要）
