# imgタグの構造（タグ名、src属性、alt属性）

### imgタグ
タグ名: img  
HTMLで画像を表示させるためのタグ  
自己完結型タグなので&lt;/img&gt;で閉じる必要がない.

### src属性
src属性とは  
画像ファイルのパスを指定する

### alt属性
alt属性とは  
スクリーンリーダーが読み上げる  
画像読み込みエラーの時の代替え表示
検索エンジンが画像の内容を理解する手掛かりになる

# パスとは
ファイルやディレクトリの場所を示す文字列  
コンピューター上で位置を指定するために使う

# 相対パスの書き方
&lt;img src="デイレクトリ名/ファイル名" alt="写真の名前"&gt;
# 画像が表示されない時の確認方法
開発者ツールのソースのエラーを確認  
内容がわからない場合はコピーして検索する

# 学んだこと
デザイン目的の画像の場合alt=""の中を空にする  
そうすることでスクリーンリーダーが読み飛ばしてくれる  
全てにつければいいということではない
